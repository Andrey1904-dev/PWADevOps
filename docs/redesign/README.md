# ТЗ №004 — реализация и проверка

Рабочий репозиторий и production остаются PWADevOps. Откат до редизайна: `auth-v3-baseline-246d791`.

## Источник дизайна

`devops-quest-rpg-redesign` возвращает 404 через Git, gh и подключённый GitHub. Локальных исходников/архивов нет. **Компонентов из него перенесено: 0**. Концепция восстановлена по ТЗ в существующем приложении. Состояние, Supabase, AuthGate, Telegram и модель XP сохранены.

## Изменения

- Оригинальная кинематографичная графика авторизации, главного экрана, 18 глав и 18 боссов.
- Вертикальная карта локаций на телефоне, сетка на desktop; реальные статусы и прогресс.
- Профиль в разделе статистики: имя, уровень, XP, игровой ранг, только реальные достижения. Ранг не является оценкой профессиональной квалификации.
- Обложки испытаний, накопительные критерии, награда до 300 XP по прежним правилам, история статусов/проверок из базы. Экран победы появляется после получения нового серверного события награды босса, а не по просмотру обложки.
- Отдельные иллюстрации дополнительных навыков Bash/Git/Cloud; общее оформление календаря/настроек и Mini App сохранено.
- Responsive WebP, ленивые обложки, preload авторизации, ограниченный runtime cache. Арты не добавлены всей коллекцией в обязательный precache. Reduced motion и fallback при ошибках картинки.
- Исправлена жёсткая метка PYTHON в миссиях остальных глав.

## Происхождение изображений

9 исходных PNG: авторизация, герой, 3 атласа глав, 3 атласа боссов, дополнительный атлас. Все действительно **сгенерированы imagegen**, оригиналы сохранены в `design/source-art`. Atlas world-a дополнительно отредактирован imagegen: удалены надписи и логотипы на экранах. Pillow используется только для кропов/сжатия без дорисовки и увеличения разрешения. `scripts/prepare-art.py` воспроизводит экспорт; исходные PNG доступны и в репозитории. Манифест содержит размеры, происхождение, SHA256 и объём каждого файла. Нативные обложки атласов имеют ограниченное разрешение (около 512–768 px по ширине), это не 4K-арты.

18 обложек глав + 18 боссов + 16 дополнительных кадров (включая фон профиля, splash и лист эмблем), 2 самостоятельных фона. Отдельные WebP-варианты не считаются новыми нарисованными изображениями. Изображения не содержат интерфейсных надписей; весь UI — HTML. HUD, рамки, прогресс и ранги оформлены программно CSS/HTML, иконки — lucide. Старый SVG города оставлен как исходный архив предыдущего оформления; внешние игровые материалы не использованы.

## Проверки и границы

TypeScript, ESLint, 41 unit/PostgreSQL, 13 Edge, 30 Playwright (Chromium desktop/iPhone viewport), production build. E2E защищённых экранов используют явно обозначенные API-адаптеры; это не доказательство native Telegram или настоящего iPhone. Дополнительно выполнен реальный аудит Supabase/Auth/RLS/Telegram API: `../evidence/live-audit-004.json`. Тестовые пользователи аудита удалены, endpoint `quest-audit` снова отвечает 410.

Свежая публичная регистрация: 200, письмо доставлено, email подтверждён, password login 200. Recovery: запрос 200, письмо доставлено, verification 303 с recovery-сессией. **Оба письма направляют не на production**: требуется URL Configuration. Не объявляется полностью проверенным автоматический возврат из почты.

Supabase: 18 глав/360 миссий; публичных таблиц без RLS — 0; активный Cron — 1. Security advisor сообщает 4 WARN для намеренно доступных authenticated SECURITY DEFINER RPC (apply_operation/ensure_profile/mini_session_status/revoke_telegram_link); проверка владельца и действующей session_id сохранена и проверена реальным аудитом. Удалять EXECUTE у этих RPC нельзя без поломки приложения. npm audit: 4 low из цепочки deepmerge → workbox-build; high/critical нет. Последняя deepmerge 4.3.1 также затронута; предложенный npm downgrade PWA-плагина не применён.

Telegram getMe/webhook/menu реально проверены. Нет подтверждённой привязки пользователя (0 соединений), поэтому реальная доставка в личный чат и запуск на устройстве ещё не подтверждены. Подписанные initData, повторные открытия, отзыв и синхронизация проверены серверными адаптерами на реальной БД; не выдаются за native Telegram-проверку.
