## Честные ограничения

Короткие ответы не оценивают свободную диагностику. Ручная проверка записывается в браузере и не удостоверяет личность наставника: для независимого подтверждения нужен реальный проверяющий. Общие навыки показывают свидетельства, но нет автоматического переноса старых отметок в новую компетентность. Облачная синхронизация нового трека требует отдельного проектирования схемы и конфликтов. Лаборатория на настоящем Mac M4/UTM здесь не запускалась, совместимость конкретных версий установщиков не проверена. Платное ПО не устанавливалось; Windows Server ARM64 не обещается.

## Запуск

В /workspace/PWADevOps: npm ci, npm run dev. Открыть адрес Vite, войти существующим аккаунтом. Используется прежняя конфигурация Supabase; для другого окружения задать VITE_SUPABASE_URL и VITE_SUPABASE_PUBLISHABLE_KEY по .env.example, не помещать service-role key во frontend.

Выбрать System Administrator → первая карточка «01. Адрес и маска» → «Открыть миссию». Возврат: кнопка DevOps RPG. Резервные копии нового трека: JOB READY.
